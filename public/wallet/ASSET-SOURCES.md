# Wallet assets

`add-to-google-wallet.svg` and `add-to-google-wallet-condensed.svg` are unmodified English (US) assets supplied by Google, downloaded on 8 October 2026 from:

https://developers.google.com/static/wallet/download-assets/add-to-wallet-svg.zip

Original archive paths:

- `add-to-wallet-svg/svg/enUS_add_to_google_wallet_wallet-button.svg`
- `add-to-wallet-svg/svg/enUS_add_to_google_wallet_add-wallet-badge.svg`

Google retains ownership of its artwork. Follow [Google's Wallet brand guidelines](https://developers.google.com/wallet/retail/loyalty-cards/resources/brand-guidelines), including aspect ratio, minimum height, clear space and unchanged appearance. This application displays these actions only when provider configuration is enabled.

The six PNG files are Nqta's generated branding assets. No Apple badge artwork is packaged.
